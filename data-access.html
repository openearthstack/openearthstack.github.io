Reference

Data Access Directory.

Where to get Sentinel-1 and other public SAR data. The main providers differ on latency, cost, and access model.

Copernicus Data Space Ecosystem (CDSE)

ESA's primary portal. Replaced the Sentinels Scientific Data Hub in 2023. Full archive of Sentinel-1 GRD, SLC, and OCN. Free account required. OData and OpenSearch APIs. High latency for older scenes; rolling archive with fast access for roughly the last 12 months.

Alaska Satellite Facility (ASF)

NASA-funded mirror of the full Sentinel-1 archive with a first-rate search UI (Vertex) and direct download. Also publishes RTC products generated from ESA's SLC and GRD. Widely used outside Europe thanks to stable URLs and global geographic coverage.

AWS Open Data

Sentinel-1 GRD scenes are hosted free in the sentinel-s1-l1c bucket. Public, requester-pays for some regions. Fast direct-from-S3 access for workloads running on AWS. No discovery API of its own; pair with CDSE or STAC for search.

Microsoft Planetary Computer

STAC-based access to Sentinel-1 RTC, GRD, and SLC with Azure-hosted compute. Free for research and public-interest use. Strong fit for teams that prefer a cloud-first notebook workflow.

Google Earth Engine

Browser/JavaScript and Python API for planetary-scale analysis on Google's infrastructure. Sentinel-1 GRD collection is preprocessed (orbit, border noise, calibration, terrain correction) to sigma0 in dB. Not downloadable at scale, but strong for exploratory analysis.

Sentinel Hub (Planet)

Commercial API with a free tier. Processes on demand through OGC-style endpoints (WMS/WMTS/OGC API Processes). Useful for web applications and non-Python stacks.
